# Política de privacidad

**YouTube Channel Stats** no recopila, almacena en servidores propios ni comparte datos personales.

- **Qué se guarda:** tu @usuario o URL de canal, tu clave de API de YouTube, el intervalo de revisión y la última lectura de estadísticas. Todo se guarda localmente en tu navegador con `chrome.storage`. Si tienes la sincronización de Chrome activada, los ajustes pueden sincronizarse entre tus dispositivos mediante tu cuenta de Google.
- **A dónde se envían datos:** únicamente a la API pública de YouTube (`https://www.googleapis.com/youtube/v3`) para consultar estadísticas públicas de canales y videos.
- **Permisos:** `storage` (guardar ajustes), `alarms` (revisar periódicamente), `notifications` (avisos) y acceso a `googleapis.com` (llamadas a la API).
- **Sin analítica, sin anuncios, sin venta de datos.**
